# Audio Guidance Clips

Pre-recorded audio clips are placed here structured by language:
- `/public/audio/en/` - English guidance audio
- `/public/audio/hi/` - Hindi guidance audio
- `/public/audio/hing/` - Hinglish guidance audio

Naming convention:
`guidance_{screenId}.mp3` (e.g. `guidance_elder_home.mp3`, `guidance_welcome.mp3`, `guidance_safeword.mp3`, etc.)

If a clip does not exist, the ReadAloudButton gracefully hides itself.
